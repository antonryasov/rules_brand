# Чек-лист запуска

Пройти сверху вниз один раз — после этого сайт и кабинет работают автономно.

## 1. Репозиторий и сайт

- [ ] Содержимое папки `rules-brand/` загружено в репозиторий `rules_brand`.
- [ ] В корне репозитория лежит `index.html` (а не `index-14.html`).
- [ ] Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
- [ ] `https://antonryasov.github.io/rules_brand/` открывается, видна шапка, главная, каталог.
- [ ] Проверены страницы: О бренде, Доставка, Возврат, Документы, Контакты, 4 промо, Квиз.
- [ ] Открывается страница товара (например, `#/candle-kodeks`), кнопка «В корзину» работает.
- [ ] На телефоне: меню открывается, карточки не разъезжаются, корзина доступна.

## 2. Worker и база

- [ ] `worker/dist/worker.js` задеплоен в Cloudflare Worker.
- [ ] Привязка D1: Variable name `DB` → `rules-orders-db`.
- [ ] `GET /health` возвращает `{"ok":true}`.
- [ ] `GET /catalog` возвращает список товаров.
- [ ] `schema.sql` выполнен (повторно — тоже можно).
- [ ] `seed.sql` выполнен, в `products` есть позиции.
- [ ] Cron Trigger `*/5 * * * *` добавлен (очередь сообщений).

## 3. Секреты

- [ ] `ADMIN_PASSWORD` — новый пароль, ≥ 16 символов (старый лучше сменить).
- [ ] `SESSION_SECRET` — случайная строка ≥ 32 символов.
- [ ] `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — на месте, тест проходит.
- [ ] `CUSTOMER_BOT_TOKEN`, `CUSTOMER_BOT_USERNAME=rules_clients_bot` — на месте.
- [ ] `WEBHOOK_SECRET` — ≥ 16 символов, только латиница/цифры/`_`/`-`.
- [ ] `ALLOWED_ORIGIN` = `https://antonryasov.github.io`.

## 4. Кабинет

- [ ] Вход по паролю работает, открывается раздел «Заказы».
- [ ] «Настройки → Тест бота для заказов» — сообщение пришло в Telegram.
- [ ] «Настройки → Подключить бота покупателей» — нажато, ошибок нет.
- [ ] Проверена страница «Товары и склад»: фото видны, цены и остатки совпадают с сайтом.

## 5. Сквозной тест заказа

- [ ] Оформить тестовый заказ на сайте (промокод, доставка, комментарий).
- [ ] Заказ появился в кабинете, в Telegram пришло уведомление.
- [ ] Нажата кнопка «Отслеживать заказ в Telegram» → бот покупателя открылся,
      `/start` привязал заказ (в карточке заказа появилось «покупатель в боте»).
- [ ] Смена статуса в кабинете → сообщение пришло в бот покупателя.
- [ ] Ответ покупателя боту → появился в переписке заказа и переслался в ваш бот.
- [ ] Отмена заказа вернула остаток на склад, повторное подтверждение — списало.
- [ ] Тестовый заказ удалён (или помечен «Отменён»).
- [ ] Остатки после теста вернулись к реальным.

## 6. Данные

- [ ] «Выгрузка данных → Полный бэкап (JSON)» скачан и сохранён.
- [ ] `data/products.json` в репозитории соответствует текущему каталогу
      (если правили в кабинете — обновите файл выгрузкой).
- [ ] В репозитории нет файлов с паролями: `.dev.vars`, `.env` (они в `.gitignore`).

## 7. Мелочи

- [ ] Тексты на страницах без опечаток, цены и сроки доставки актуальны.
- [ ] Реквизиты в `data/settings.json` (`brand.legal`, `contacts`) заполнены.
- [ ] Ссылки на Telegram/VK/почту работают.
- [ ] Номер заказа и трек-номер не показываются посторонним (заказ открывается по ссылке с токеном).
