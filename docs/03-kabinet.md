# Личный кабинет (CRM)

Адрес: `https://ВАШ-WORKER.workers.dev/admin`
Вход: пароль из секрета `ADMIN_PASSWORD` (Cloudflare → Worker → Settings → Variables and Secrets).
Сессия действует 12 часов, после этого нужно войти заново.

---

## Обзор

Первая страница после входа показывает:

- **Заказов сегодня** — сколько пришло и на какую сумму;
- **Новых заказов** — те, что ждут подтверждения;
- **Выручка в работе** — сумма подтверждённых, собираемых и отправленных;
- **Товаров активных** — сколько позиций в каталоге;
- **Подписчиков бота** — база для рассылок;
- **Очередь Telegram** — если есть ошибки отправки, покажет красным;
- **Последние заказы** — клик открывает карточку;
- **Мало на складе** — позиции, где осталось 3 и меньше.

## Заказы

### Список

- Поиск по номеру, имени, телефону, городу.
- Фильтр по статусу и по датам.
- Кнопка «Выгрузить CSV» — сохранит текущую выборку заказов в файл.

### Карточка заказа (открывается кликом)

**Статус и доставка**

| Поле | Что делает |
|---|---|
| Статус заказа | Новый → Подтверждён → Собирается → Отправлен → Доставлен / Отменён |
| Оплата | Не оплачен / Оплачен / Возврат |
| Доставка | способ (СДЭК, Почта, курьер) |
| Стоимость доставки | сколько берёте за доставку |
| Трек-номер | номер посылки |
| уведомить покупателя | галочка: отправить в Telegram сообщение о смене статуса |

Важные правила:

- При смене статуса или трек-номера покупателю **автоматически** уходит сообщение
  в бота (если он привязал заказ — об этом говорит подпись «покупатель в боте»).
- При переводе в **«Отменён»** остатки товаров возвращаются на склад.
  Если вернуть заказ в работу — остатки снова списываются.

**Покупатель** — можно поправить имя, телефон, город, контакт и комментарий.

**Состав заказа**

- «−/+» меняют количество, поле цены можно править вручную;
- «Добавить товар из каталога» — выбрать из списка, подставится актуальная цена;
- «Добавить строку вручную» — для доставки, открытки, услуги;
- после правок нажмите **«Пересчитать состав»** — суммы и промокод пересчитаются.

**Заметка продавца** — внутренняя, покупатель её не видит.

**Переписка с покупателем**

- Пишете сообщение → галочка «отправить покупателю в Telegram» → «Добавить комментарий».
- Сообщение уходит покупателю и остаётся в истории заказа.
- Все изменения статуса фиксируются в переписке автоматически (серые строки).
- Если покупатель написал боту — его сообщение появится в этой же ленте
  с пометкой «покупатель», а вам придёт уведомление в бот заказов.

**Кнопки в шапке карточки**

- «Отправить статус» — повторно отправить покупателю текущий статус;
- «Удалить» — удалить заказ полностью (остатки при этом не возвращаются).

## Товары и склад

Таблица показывает все позиции: фото, название, тип, цена, остаток, порядок, видимость.

**Быстрая правка:** поменяйте цену или остаток прямо в строке → нажмите
**«Сохранить изменения»**. На сайте новые значения появятся в течение 30 секунд.

**Редактор товара** (кнопка «Править»):

| Поле | Смысл |
|---|---|
| ID | внутренний код (латиницей). У нового товара придумайте свой |
| Название / Полное название | как в каталоге и как в корзине |
| Тип | `candle`, `diffuser` или `set` |
| Коллекция, код коллекции | «Сила»/`sila`, «Горы»/`gory` — используются промокодами |
| Цена, Старая цена | ₽ |
| Остаток | при 0 на сайте «Нет в наличии», кнопка «В корзину» блокируется |
| Порядок вывода | меньше число — выше в каталоге |
| Короткое описание | строка под названием |
| Слоган | крупная фраза на странице товара |
| Описание | абзац под слоганом |
| Ноты | верх / сердце / база |
| Характеристики | по строке формата `Состав: соевый воск…` |
| Безопасность | блок внизу страницы товара |
| Фото для каталога / большое фото | ссылка на файл **или** кнопка «Загрузить» (фото сожмётся и сохранится в базе) |
| Показывать на сайте | снять галочку — товар скрыт, но остаётся в базе |

Кнопка «Удалить товар» убирает позицию из каталога (заказы, где он был, сохранятся).

## Импорт товаров

Кнопка «Импорт» в разделе «Товары и склад».

1. Подготовьте файл CSV (Excel → «Сохранить как CSV») или возьмите выгрузку
   «Товары (CSV)» из раздела «Выгрузка данных».
2. Колонки: `id;name;price;old_price;stock;type;type_label;family;collection;active;sort;tagline;image_card`
   (разделитель `;` или `,`, первая строка — заголовки).
3. Загрузите файл или вставьте текст → «Импортировать».

Режимы:

- **обновить** (по умолчанию) — позиции с совпадающим `id` обновятся, новые добавятся;
- **удалить товары, которых нет в файле** — каталог станет ровно таким, как в файле.

Можно загрузить и JSON — например, выгрузку «Товары (JSON)».

Пример CSV:

```
id;name;price;old_price;stock;type;type_label;family;collection;active;sort;tagline;image_card
candle-kodeks;Кодекс · свеча 200 г;1690;1990;12;candle;Свеча 200 г;sila;Сила;1;10;Кожа, табак, амбра;assets/img/products/candle-kodeks.webp
```

## Выгрузка данных

Раздел «Выгрузка данных» — файлы формируются из базы в момент скачивания:

| Файл | Что внутри |
|---|---|
| Заказы (CSV) | все заказы: дата, статус, покупатель, состав, суммы, трек, комментарии |
| Заказы (JSON) | полные записи + позиции + переписка |
| Товары (CSV) | каталог с ценами и остатками — годится для правки и обратной загрузки |
| Товары (JSON) | каталог с описаниями, нотами, характеристиками |
| Переписка (CSV) | все комментарии по заказам |
| Подписчики (CSV) | chat_id подписчиков бота |
| Полный бэкап (JSON) | заказы, товары, комментарии, подписчики, новости — один файл |

CSV открывается в Excel и Google Таблицах (разделитель `;`, UTF-8).
Совет: раз в неделю скачивайте «Полный бэкап» и храните у себя.

## Клиенты

Список покупателей, собранный из заказов: имя, телефон, город, число заказов,
общая сумма, дата последнего заказа. Отсортировано по сумме — сразу видно постоянных.

---

## Рассылка

- Новость подписчикам бота (текст до 1200 символов), уходит тем, кто нажал «Start».
- История прошлых новостей.
- Очередь сообщений: что отправлено, что в процессе, что с ошибкой.
  «Повторить неудачные» — запустить повторную отправку.

---

## Настройки

- **Тест бота для заказов** — отправляет вам одно сообщение, чтобы проверить токены.
- **Подключить бота покупателей** — регистрирует вебхук (делается один раз;
  после смены домена Worker нужно нажать снова).
- Шпаргалка «что где менять» и выход из кабинета.

---

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Не приходят заказы в Telegram | «Настройки» → «Тест бота»; секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Покупатель не получает статусы | покупатель должен один раз нажать «Отслеживать заказ в Telegram» после оформления; в карточке заказа должно быть «покупатель в боте» |
| На сайте старые цены | обновите страницу сайта (Ctrl+Shift+R); проверьте, что сайт берёт каталог из Worker (`data/settings.json` → `api.base`) |
| В кабинете не видно фото товара | фото должно быть ссылкой вида `assets/img/products/…` и существовать в репозитории |
| «Сессия истекла» | войдите заново — сессия живёт 12 часов |
