# Товары и склад

Каталог хранится в базе D1 (таблица `products`) и правится из кабинета.
Файл `data/products.json` — резервная копия и исходник для первичной заливки.

---

## Три способа изменить товар

### 1. Быстро: цена и остаток в таблице

«Товары и склад» → меняете число в колонке «Цена» или «Остаток» →
**«Сохранить изменения»**. На сайте обновится через 30 секунд.

### 2. Полностью: редактор товара

Кнопка «Править» в строке товара. Можно изменить всё: названия, описания,
ноты, характеристики, фото, порядок вывода, видимость.

Полезные поля:

| Поле | Зачем |
|---|---|
| `Порядок вывода` | чем меньше, тем выше в каталоге |
| `Показывать на сайте` | снятая галочка = товар скрыт (для снятых с продажи) |
| `Остаток` | `0` → «Нет в наличии», заказ оформить нельзя |
| `Старая цена` | показывается зачёркнутой |

### 3. Массово: импорт CSV/JSON

«Импорт» → выбрать файл или вставить текст.

Колонки CSV (первая строка — заголовки, разделитель `;` или `,`):

```
id;name;price;old_price;stock;type;type_label;family;collection;active;sort;tagline;image_card
candle-kodeks;Кодекс · свеча 200 г;1690;1990;12;candle;Свеча 200 г;sila;Сила;1;10;Кожа, табак, амбра;assets/img/products/candle-kodeks.webp
```

- `id` — ключ. Если такой товар есть, он обновится; если нет, добавится.
- `active` — `1`/`0` (показывать на сайте).
- Режим «удалить товары, которых нет в файле» делает каталог ровно по файлу.

## Фотографии товаров

### Загрузить с компьютера

«Править» → «Фото для каталога» → **«Загрузить»**.
Фото сожмётся до 900 px, сохранится в базе и сразу появится на сайте.

Учтите: так фото живёт только в базе. Если хотите держать картинки в
репозитории (быстрее грузятся), загрузите файл в `assets/img/products/`
и вставьте в поле ссылку `assets/img/products/имя.webp`.

### Требования к фото

| Параметр | Значение |
|---|---|
| Формат | `.webp` (лучше), `.jpg`, `.png` |
| Размер | 1200–1600 px по длинной стороне |
| Вес | до 300 КБ |
| Фон | тёмный или нейтральный, товар по центру |

### Галерея (несколько фото на странице товара)

В редакторе — поле «Галерея», по одному пути в строке:

```
assets/img/products/candle-kodeks.webp
assets/img/products/candle-kodeks-hero.webp
assets/img/pages/craft.webp
```

## Остатки: как работает списание

- Оформление заказа: остаток уменьшается на количество сразу при приёме заказа.
- Отмена заказа в кабинете: остаток возвращается.
- Повторное подтверждение отменённого: списывается снова.
- Если товара не хватает, покупатель увидит «Осталось N шт.» и не сможет
  положить в корзину больше, чем есть.

Позиции с остатком ≤ 3 попадают в блок «Мало на складе» на «Обзоре».

## Новый товар: пошагово

1. Подготовьте фото, положите файл в `assets/img/products/` (необязательно —
   можно сразу загрузить через кабинет).
2. «Товары и склад» → **«+ Товар»**.
3. Заполните: ID (латиницей, например `candle-veter`), название, полное название,
   тип (`candle`/`diffuser`/`set`), коллекция и её код (`sila`, `gory`), цена,
   остаток, порядок вывода.
4. Вставьте короткое описание, слоган, описание, ноты, характеристики.
5. Укажите фото (ссылку или загрузите).
6. «Сохранить». Товар сразу появится в каталоге по адресу
   `#/candle-veter.html` — страница создаётся автоматически.

> Страницу товара отдельно создавать не нужно: она собирается из данных карточки.

## Как связаны файл и база

| Что | Где главное |
|---|---|
| Цена, остаток, видимость | **база** (кабинет) |
| Названия, описания, фото | база, но исходные значения берутся из `data/products.json` |
| Если Worker недоступен | сайт показывает `data/products.json` |

Порядок обновления резервной копии после крупных правок:

1. Кабинет → «Выгрузка данных» → «Товары (JSON)».
2. Сохраните файл как `data/products.json` в репозитории (замените старый).
3. Закоммитьте. Теперь резервная копия совпадает с базой.
